¿Qué es un virus informático?

Definición formal, ciclo de vida y diferencias con otros tipos de malware.

Definición formal IEEE/NIST

Un virus informático es un programa que se auto-replica adjuntando copias de sí mismo a otros archivos o programas ejecutables, requiriendo la ejecución del huésped para propagarse. A diferencia de los gusanos (worms), no se propaga sin intervención del usuario o del sistema.

Ciclo de vida universal — 4 fases
① Infección (Insertion)
El virus copia su código en el huésped (archivo ejecutable, sector de boot, macro, script). Puede ser directo o indirecto (RAM residente).
② Latencia (Incubation)
El virus espera una condición de activación: fecha específica, número de ejecuciones, presencia de archivo, acción del usuario.
③ Propagación (Replication)
Busca y contamina nuevos huéspedes. Puede usar sistema de archivos, red, dispositivos removibles, email, etc.
④ Ejecución del Payload
Acción maliciosa: corrupción de datos, exfiltración, cifrado (ransomware), pantalla de muerte, backdoor, DDoS, espionaje.

Historia de los Virus

De la teoría de von Neumann a los ataques modernos a infraestructura crítica.

1949

Teoría de Autómatas Auto-replicantes

John von Neumann publica "Theory of Self-Reproducing Automata". Primer modelo matemático de un programa capaz de copiarse a sí mismo.

1971

Creeper — El primer "virus" experimental

Bob Thomas crea Creeper en ARPANET: mostraba "I'm the creeper, catch me if you can!" y se movía entre sistemas. Reaper fue creado para eliminarlo.

1982

Elk Cloner — Primer virus masivo

Rich Skrenta (15 años) crea Elk Cloner para Apple II en disquetes. Se propagó fuera del control de su autor — primer virus "in the wild".

1986

Brain — Primer virus para PC/DOS

Hermanos Alvi (Pakistán) crean Brain como "protección de copyright". Infectó el sector de boot de disquetes 360KB. Primer virus de boot sector documentado.

1988

Morris Worm — Primera epidemia de red

Robert Morris lanza el primer gusano de internet. Afectó ~6,000 máquinas (10% de ARPANET). Primera condena bajo la Computer Fraud and Abuse Act.

1998

CIH (Chernobyl) — Nivel destructivo nuevo

Chen Ing-hau crea CIH. Sobrescribía los primeros 1MB del disco duro Y flasheaba la BIOS el 26 de abril. Dejó millones de PCs inoperables.

1999

Melissa — Macro virus + email

Primera gran epidemia de macro virus. Se propagó por Outlook enviando el documento infectado a los primeros 50 contactos. Colapsó servidores de email.

2010

Stuxnet — Cyberweapon de estado

Primer virus/gusano diseñado como arma: destruyó físicamente centrifugadoras iraníes modificando PLCs Siemens. Atribuido a EEUU e Israel. Hito en cyberwarfare.

Anatomía de un Virus

Estructura interna de un infector de archivos PE32 (Windows). Componentes universales y opcionales.

estructura_virus_pe32.py — simulación educativa 
# ─── ANATOMÍA DE UN INFECTOR DE ARCHIVOS (PE32) ─────────────────────────────
# COMPONENTES UNIVERSALES (toda muestra de virus los tiene)
# COMPONENTES OPCIONALES  (varían por familia)

class VirusSimulado:
    """
    Simulación académica — NO ejecutable en producción.
    Demuestra la estructura conceptual de un infector de archivos.
    Entorno: VM Windows 10 aislada, red host-only.
    """

    def __init__(self):
        # ── 1. VECTOR DE INFECCIÓN ──────────────────────────────────
        # Cómo el virus llega a un nuevo huésped.
        # Ejemplos reales: email adjunto, USB, descarga, exploit
        self.vector = "archivo_PE32_modificado"

        # ── 2. RUTINA DE BÚSQUEDA (Finder) ──────────────────────────
        # El virus busca huéspedes candidatos (otros .exe, .dll, etc.)
        self.extensiones_objetivo = ['.exe', '.dll', '.com']

        # ── 3. MECANISMO DE REPLICACIÓN (Infector) ──────────────────
        # Adjunta/inserta el cuerpo viral al huésped
        self.metodo_infeccion = "append_al_final_de_seccion_code"

        # ── 4. TRIGGER / BOMBA LÓGICA (opcional) ────────────────────
        # Condición de activación del payload
        self.trigger = "fecha == '1999-04-26'"  # CIH usó esta fecha

        # ── 5. PAYLOAD ──────────────────────────────────────────────
        # La acción dañina. Puede ser: borrar, cifrar, espiar, etc.
        self.payload = "mostrar_mensaje"       # payload benigno para lab

        # ── 6. ANTI-DETECCIÓN (opcional) ────────────────────────────
        # Técnicas: cifrado, polimorfismo, anti-debug, rootkit
        self.evasion = "xor_simple_key_0x37"

    def buscar_huespedes(self, directorio: str) -> list:
        """Fase 1: Scan de archivos ejecutables candidatos."""
        import os
        candidatos = []
        for root, dirs, files in os.walk(directorio):
            for f in files:
                if any(f.endswith(ext) for ext in self.extensiones_objetivo):
                    candidatos.append(os.path.join(root, f))
        return candidatos

    def ya_infectado(self, archivo: str) -> bool:
        """Marcador de infección (evita re-infección).
        Virus reales usan firmas, checksums, bytes específicos."""
        with open(archivo, 'rb') as f:
            contenido = f.read()
        FIRMA = b'\xDE\xAD\xBE\xEF'   # firma del virus en el huésped
        return FIRMA in contenido

    def infectar_archivo(self, archivo: str) -> bool:
        """Fase 2: Adjunta cuerpo viral al huésped (simulado).
        REAL: modifica entry point PE, redirige ejecución al virus."""
        if self.ya_infectado(archivo):
            return False  # no re-infectar
        # En simulación solo añadimos la firma — no código ejecutable
        with open(archivo, 'ab') as f:
            f.write(b'\xDE\xAD\xBE\xEF' + b'[VIRUS_SIM]')
        return True

    def verificar_trigger(self) -> bool:
        """Fase 3: Comprueba condición de disparo."""
        from datetime import date
        return date.today().strftime('%m-%d') == '04-26'

    def ejecutar_payload(self):
        """Fase 4: Acción del payload (benigna en lab)."""
        print(f"[LAB] Payload activado el {__import__('datetime').date.today()}")
        print("[LAB] En virus real: borrado, cifrado, exfiltración, etc.")

Script de análisis estático básico Python
analisis_estatico.py 
import hashlib, os, sys, struct
from pathlib import Path

def analizar_archivo(ruta: str):
    """Análisis estático básico de un ejecutable sospechoso."""
    p = Path(ruta)
    data = p.read_bytes()

    print(f"\n{'='*55}")
    print(f"  ANÁLISIS ESTÁTICO: {p.name}")
    print(f"{'='*55}")

    # ── Hashes ──────────────────────────────────────────────
    md5  = hashlib.md5(data).hexdigest()
    sha1 = hashlib.sha1(data).hexdigest()
    sha256 = hashlib.sha256(data).hexdigest()
    print(f"\n[HASH]")
    print(f"  MD5   : {md5}")
    print(f"  SHA1  : {sha1}")
    print(f"  SHA256: {sha256}")
    # → Buscar en VirusTotal, MalwareBazaar, Hybrid Analysis

    # ── Firma PE ─────────────────────────────────────────────
    es_pe = data[:2] == b'MZ'
    print(f"\n[FORMATO]")
    print(f"  Tipo   : {'PE32 (Windows)' if es_pe else 'No-PE'}")
    print(f"  Tamaño : {len(data):,} bytes")

    # ── Strings sospechosas ──────────────────────────────────
    strings = extraer_strings(data, min_len=5)
    keywords = ['http', 'cmd.exe', 'powershell', 'regedit',
                'HKEY_', 'CreateRemoteThread', 'VirtualAlloc',
                'WriteProcessMemory', 'WScript', 'AutoOpen']
    sospechosas = [s for s in strings if any(k.lower() in s.lower()
                                                  for k in keywords)]
    print(f"\n[STRINGS SOSPECHOSAS] ({len(sospechosas)} encontradas)")
    for s in sospechosas[:15]:
        print(f"  ⚠  {s}")

    # ── Firma de virus conocida en este lab ──────────────────
    FIRMAS_LAB = {
        b'\xDE\xAD\xBE\xEF': 'VirusSimulado_Lab (firma DEAD BEEF)',
        b'[VIRUS_SIM]': 'Marcador de infección lab',
    }
    print(f"\n[DETECCIÓN DE FIRMAS]")
    encontrado = False
    for firma, nombre in FIRMAS_LAB.items():
        if firma in data:
            print(f"  🔴 INFECTADO: {nombre}")
            encontrado = True
    if not encontrado:
        print(f"  🟢 Sin firmas conocidas del lab")

def extraer_strings(data: bytes, min_len=4) -> list:
    """Extrae strings ASCII del binario (como 'strings' en Unix)."""
    result, current = [], []
    for b in data:
        if 0x20 <= b <= 0x7e:
            current.append(chr(b))
        elif current:
            if len(current) >= min_len:
                result.append(''.join(current))
            current = []
    return result

if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("Uso: python analisis_estatico.py <archivo>")
    else:
        analizar_archivo(sys.argv[1])
